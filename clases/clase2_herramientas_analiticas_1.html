01 · El Stack Analítico
¿Qué herramienta para qué problema?
20 min · El error más común: usar la herramienta favorita, no la correcta
Pregunta de arranque

Te llega el reporte mensual de regalías en un PDF de 40 páginas. ¿Por dónde empiezas?

La respuesta revela inmediatamente qué tan ordenado está tu stack analítico. Un analista sin criterio de herramientas pierde horas antes de siquiera ver un dato útil.

Fundación
📊
Excel / Sheets
Cuándo usarlo
Exploración inicial, tablas dinámicas, reportes para stakeholders no técnicos, datasets menores a 100K filas. La primera capa de todo análisis.
Consulta
🗄️
SQL
Cuándo usarlo
Cuando los datos viven en una base de datos. Joins entre tablas, filtros complejos, agregaciones sobre millones de registros. Más rápido y preciso que Excel para eso.
Automatización
⚡
Power Query
Cuándo usarlo
Cuando recibes el mismo reporte cada mes y lo limpias manualmente. Power Query lo automatiza con un clic. Vive dentro de Excel, no requiere código.
IA / LLMs
🤖
Claude / ChatGPT
Cuándo usarlo
Para generar fórmulas, explicar errores, limpiar datos con instrucciones en lenguaje natural, entender un dataset nuevo en segundos. El copiloto analítico.
Regla de esta clase

El stack no es una jerarquía. No hay herramienta superior. Hay herramienta correcta para el problema correcto. Un analista experto sabe cuándo cada una entra al juego — y cuándo combinarlas.

02 · Fórmulas Esenciales
Las fórmulas que responden preguntas de negocio
25 min · No son todas las fórmulas — son las que un analista musical usa de verdad
Elige una fórmula para ver cómo funciona en contexto musical
SUMAR.SI / SUMAR.SI.CONJUNTO
¿Cuánto bajo una condición?
=SUMAR.SI(rango; criterio; suma)
Suma selectiva. El SUMIFS permite múltiples condiciones simultáneas — más poderoso para análisis reales.
🎵 Revenue total solo de canciones del género urbano en Q1
CONTAR.SI / CONTAR.SI.CONJUNTO
¿Cuántas veces ocurre algo?
=CONTAR.SI(rango; criterio)
Cuenta registros que cumplen una condición. Esencial para frecuencias, rankings y detección de patrones.
🎵 ¿Cuántas canciones del catálogo superaron 50K streams este mes?
BUSCARV / BUSCARX
¿Qué dato tiene este registro en otra tabla?
=BUSCARV(valor; tabla; col; 0)
Conecta tablas. XLOOKUP es más moderno y flexible — busca en cualquier dirección y maneja errores solo.
🎵 Traer el género de cada canción desde el catálogo maestro
PROMEDIO.SI
¿Cuál es el promedio de un segmento?
=PROMEDIO.SI(rango; criterio; promedio)
El promedio global puede esconder diferencias importantes entre segmentos. PROMEDIO.SI las expone.
🎵 Save rate promedio: canciones lanzadas con campaña vs sin campaña
SI.ERROR
¿Qué mostrar cuando algo falla?
=SI.ERROR(formula; "N/D")
Los datos reales tienen huecos. SI.ERROR evita que un error rompa toda la hoja. Señal de análisis robusto y defensivo.
🎵 Si no hay dato de revenue para una canción, mostrar "N/D" en lugar de #N/A
TEXTO / FECHANUMERO
¿Cómo estandarizar fechas y texto?
=TEXTO(fecha; "AAAA-MM")
Las fechas son el campo más sucio en reportes musicales. Llegan en 5 formatos distintos. TEXT y DATEVALUE las unifican.
🎵 Estandarizar "abril 2026", "04/2026" y "2026-04" en un solo formato

03 · Limpieza de Datos en Excel
El 70% del trabajo analítico real
25 min · Los errores más frecuentes en reportes musicales y cómo resolverlos

Por qué los datos llegan sucios

Los reportes de Spotify, Apple Music, distribuidoras y plataformas de tickets no tienen un estándar unificado. Cada fuente exporta fechas, nombres y números en formatos distintos. Cuando los consolidas, el caos aparece solo.

La regla de oro

Nunca analices datos que no hayas auditado primero. Un dato sucio produce un insight falso. En la industria musical eso se traduce en decisiones incorrectas: campañas mal dirigidas, presupuestos mal asignados, lanzamientos mal programados.

04 · Power Query
Automatizar lo que hacías a mano
20 min · Cuando el mismo reporte llega cada mes, no lo limpies dos veces
El problema que resuelve

Recibes el reporte de Spotify cada primer lunes del mes. Y cada mes haces los mismos 12 pasos de limpieza.

Power Query graba esos pasos como una secuencia reutilizable. El segundo mes solo abres el archivo y haces clic en "Actualizar". Eso es automatización sin código.

¿Qué es Power Query?

Una herramienta de transformación de datos que vive dentro de Excel y Google Sheets. No requiere programar. Cada transformación se registra como un paso visible y editable.

Es el paso entre "limpiar a mano" y "programar en Python".

Cuándo NO usarlo

Si el dataset cambia de estructura cada mes (columnas distintas, fuentes distintas), Power Query requiere mantenimiento constante.

Para datasets únicos o de estructura variable, la limpieza manual con fórmulas es más rápida.

Flujo Power Query — Consolidación mensual de streaming
Así se ve la secuencia de pasos en el editor de Power Query
FLUJO VISUAL
1
Importar fuente

Conectas el archivo .xlsx o .csv de la distribuidora. Power Query lo lee sin abrirlo en Excel primero.

Datos → Obtener datos → Desde archivo
2
Promover encabezados

Si la primera fila tiene los nombres de columna, los conviertes en encabezados reales con un clic.

Inicio → Usar la primera fila como encabezado
3
Cambiar tipos de dato

Defines explícitamente qué columnas son números, fechas o texto. Power Query detecta automáticamente pero siempre hay que verificar.

Seleccionar columna → Tipo de dato → Número entero / Fecha
4
Limpiar texto

Eliminas espacios, estandarizas mayúsculas y reemplazas valores inconsistentes en columnas de texto como nombres de artistas o géneros.

Transformar → Formato → Recortar / Poner en mayúsculas
5
Filtrar y eliminar duplicados

Eliminas filas vacías, registros duplicados y valores fuera de rango. Todo queda registrado como paso reversible.

Inicio → Quitar filas → Quitar duplicados
6
Cargar a Excel

El resultado limpio se carga como tabla en tu hoja. El mes siguiente, con el mismo archivo actualizado, solo haces clic en "Actualizar todo".

Inicio → Cerrar y cargar → Como tabla
Valor real de Power Query

No es que te ahorre 20 minutos el primer mes. Es que te ahorra 20 minutos × 12 meses × todos los reportes que manejas. Y elimina el error humano de repetir los mismos pasos a mano.

05 · LLMs como Copiloto Analítico
Claude y ChatGPT como herramientas de análisis
20 min · No son sustitutos del analista — son multiplicadores de velocidad

Qué pueden hacer por ti

Generar fórmulas en segundos. Explicar por qué una fórmula da error. Limpiar datos con instrucciones en español. Sugerir qué análisis aplicar a un dataset. Escribir queries SQL. Interpretar resultados.

Todo sin salir de tu flujo de trabajo.

Qué NO pueden hacer

Tomar decisiones por ti. Conocer el contexto de tu negocio sin que se los expliques. Garantizar que el resultado es correcto sin que lo valides.

El LLM es tan bueno como el prompt que le das — y tan confiable como tu criterio para verificar.

Caso de uso 1 — Generar fórmula
Tienes el problema, no la fórmula
Tengo una tabla en Excel con columnas: Canción (A), Género (B), Streams (C), Revenue (D). Necesito una fórmula que sume el revenue total solo de las canciones del género Urbano y que tengan más de 500,000 streams.
El LLM genera en segundos:

=SUMAR.SI.CONJUNTO(D2:D100; B2:B100; "Urbano"; C2:C100; ">"&500000)

Con explicación paso a paso de cada argumento. Lo que antes tomaba 10 minutos buscando en Google.
Caso de uso 2 — Diagnosticar error
Tu fórmula da #VALUE! y no sabes por qué
Esta fórmula me da error #VALUE!: =SUMAR.SI(B2:B50; "Urbano"; C2:C50). La columna C tiene números pero algunos tienen comas como separador de miles. ¿Cuál es el problema?
El LLM diagnostica: los números con coma se leen como texto, no como números. Solución:

=SUMAPRODUCTO((B2:B50="Urbano")*VALOR(SUSTITUIR(C2:C50;",";"")))

O bien: seleccionar columna C → Datos → Texto en columnas para convertir.
Caso de uso 3 — Limpiar con instrucciones
Tienes texto inconsistente y no sabes por dónde empezar
Tengo una columna con nombres de artistas: "norte verdadero", " Norte Verdadero ", "NORTE VERDADERO", "Norte verdadero". ¿Qué fórmulas de Excel uso para estandarizarlos todos a "Norte Verdadero"?
Respuesta inmediata:

=NOMPROPIO(ESPACIOS(A2))

TRIM elimina espacios. PROPER capitaliza la primera letra de cada palabra. Para casos especiales como "DJ" o "MC", instrucciones adicionales con SUBSTITUTE.
Caso de uso 4 — Entender un dataset nuevo
Te llega un reporte que nunca habías visto
Aquí está la primera fila de un reporte de Spotify for Artists: [pegas el encabezado]. ¿Qué significa cada columna y cuáles son las más importantes para analizar el crecimiento de un artista emergente?
El LLM explica cada campo, prioriza las columnas más relevantes y sugiere qué preguntas puedes responder con ese dataset. 5 minutos de orientación vs 1 hora de exploración a ciegas.
Advertencia crítica

Un LLM puede generar una fórmula incorrecta con total confianza. Siempre verifica el resultado contra un caso donde ya sabes la respuesta. El criterio analítico es tuyo — el LLM solo acelera la ejecución.

¿Por dónde empiezas y qué herramienta usas en cada paso?
1
LLM — Claude / ChatGPT

6
LLM — Redacción de insight
"Aquí están mis resultados: [pegas los números]. ¿Cómo redactaría esto como insight para presentar a un manager no técnico?" El LLM te da el lenguaje. Tú validas la lógica.

Puntos clave de esta clase

Lo que debes poder explicar después de hoy.

  • ✓ El stack analítico: Excel, Power Query, SQL y LLMs — cada uno tiene su momento.
  • ✓ Las fórmulas esenciales responden preguntas de negocio, no solo calculan.
  • ✓ Un dato sucio produce un insight falso — auditar antes de analizar.
  • ✓ Power Query automatiza la limpieza repetitiva sin código.
  • ✓ Los LLMs aceleran la ejecución. El criterio analítico sigue siendo tuyo.
  • ✓ La herramienta correcta depende del problema, no de la preferencia.
